Report a service problem to the county

Use this portal to report problems such as a broken streetlight, a water fault or missed garbage collection. You will get a reference number and can follow the request until the county resolves it.

{% if current_user %} Go to my dashboard {% else %} Register to submit a request Sign in {% endif %} Track a request

How to use this portal

  1. Register for a resident account and sign in.
  2. Choose a category, say where the problem is, describe it and attach a photo if you have one.
  3. Keep the reference number you receive, for example PSR-2026-000001.
  4. Follow the status: Pending, In Progress, then Resolved. If officers need more details, you will be asked to reply on the request page.

Services you can report

  • StreetlightsFaulty or missing street lighting
  • Water supplyBurst pipes, outages and sewer blockages
  • Garbage collectionMissed collection and illegal dumping
  • Roads and drainagePotholes, damaged roads and blocked drains
